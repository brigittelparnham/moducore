Journal Embed Test

This page simulates an external site embedding a moducore journal feed. Replace YOUR_TOKEN_HERE with a token from Settings → Embed Tokens.

My Journal

How to test this
  1. Start the API: pnpm dev (from repo root)
  2. Log into the CMS (http://localhost:3001)
  3. Settings → Embed Tokens → Create Token
  4. Copy the token value
  5. Build the embed bundle: PATH="/opt/homebrew/bin:/usr/bin:/bin:$PATH" pnpm --filter @moducore/embeds build
  6. Replace YOUR_TOKEN_HERE in this file with the copied token
  7. Open this HTML file via a local server (e.g. npx serve .) — not file://
