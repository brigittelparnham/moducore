How to test
  1. Start: pnpm dev
  2. Log into CMS at http://localhost:3001
  3. Publish at least one journal entry and one CMS page
  4. Settings → Embed Tokens → Create Token → copy the value
  5. Build: PATH="/opt/homebrew/bin:/usr/bin:/bin:$PATH" pnpm --filter @moducore/embeds build
  6. Replace placeholders in this file
  7. Serve: npx serve . and open the URL shown
